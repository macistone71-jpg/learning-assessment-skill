# 企业级 AI 知识检测与学习诊断 Skill

> 从“笔记生成几道题”升级为“知识模型—考试蓝图—候选题池—质量门禁—人工审核—作答诊断—补练再测”的完整测评系统。

## 项目定位

该项目源自 AI 教育业务场景，服务教师、教研员、题库运营、教学管理者和学生。它关注的不是出题速度本身，而是：

- 题目是否真正测到学习目标；
- 答案、解析和来源是否可靠；
- AI 题目如何经过规则与人工审核进入题库；
- 作答结果能否形成谨慎、可解释的知识点诊断；
- 补练后是否有新的迁移证据。

## 企业级链路

```text
课程包/教材/笔记/题库
          ↓
AssessmentBrief
          ↓
知识模型与考试蓝图
          ↓
候选题池（1.3–2倍）
          ↓
答案/来源/难度/重复/公平性检查
          ↓
教师审核 → 教研审核 → 题库
          ↓
组卷与平台导出
          ↓
作答证据 → 知识点诊断 → 补练 → 再测
```

## 相比初版的变化

- 从固定“60/30/10”出题升级为按目的设计考试蓝图；
- 增加 low/medium/high 测评风险分级；
- 增加知识点、学习目标、题目和来源的证据链；
- 增加候选题池、人工审核状态和题库版本治理；
- 增加单选唯一答案、Rubric、重复题和 STEM 确定性校验；
- 区分预估难度与基于真实数据校准的难度；
- 增加证据式诊断，避免“一题答错=不会”的过度结论；
- 增加错误类型、补练、迁移再测和上线后题目分析；
- 增加隐私、公平、无障碍和高风险决策边界；
- 增加结构化 assessment package、示例和可执行验证器；
- 修正“没有真实适配器却承诺自动生成考试链接”的问题。

## 快速使用

准备以下信息：

```text
测评目的：诊断/形成性/总结性/练习
风险等级：low/medium/high
目标学员：
课程材料或题库：
时长与分值：
题型与评分方式：
导出平台或通用格式：
审核角色：
```

验证示例：

```bash
python3 scripts/validate_assessment_package.py examples/assessment-package.example.json
```

验证器检查结构、ID、蓝图覆盖、分值、来源、单选答案和审核状态，不替代专业测量效度验证。

## 学科工具与互动解析

对于立体几何、解析几何和化学反应等 STEM 题，可选对接 `wy51ai/edulab`：使用 SymPy 等确定性计算驱动答案、步骤和互动可视化，并检查四者同源一致。外部插件不可用时，必须明确降级，不用模型心算冒充验证。

## 企业项目展示建议

面试时重点展示真实的候选题审核通过率、人工修改率、答案错误率、蓝图覆盖、组卷时间、单题成本、题目通过率、区分度、干扰项表现、补练完成率和再测变化。没有真实数据时标记“待校准”。
