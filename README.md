# 笔记转 AI 考试

> 上完课后，把笔记交给 AI，自动生成一份线上考试链接。AI 解析知识点 → 智能出题 → 生成考试，形成「学 → 测 → 反馈」闭环。

## 项目定位

这是一个「AI + 教育」的产品方案，解决学习闭环中最薄弱的一环——**测评**。

学习闭环是：学（上课）→ 测（考试）→ 反馈（知道哪里不会）。但「测」这环，卡在老师手动出题这道坎上——费时费力，所以很多课干脆不测。不测，学生不知道自己会不会，老师不知道讲没讲清。

这个项目用 AI 把「出题」自动化，让闭环真正转起来。

## 解决的痛点

| 痛点 | 现状 | 方案 |
|------|------|------|
| 出题费时 | 一份试卷要 1-2 小时 | 笔记丢给 AI，几分钟出卷 |
| 闭环断裂 | 很多课「上完就完了」 | 每节课后自动生成测评 |
| 反馈缺失 | 学生不知道哪里不会 | 每题带解析 + 错题补练 |

## 核心流程

```
课堂笔记 → AI 解析知识点 → 智能出题 → 生成考试链接 → 错题反馈
```

关键设计：**先解析知识点，再出题**。直接让 AI 从笔记出题，题目容易抓不住重点；先让 AI 提取「这节课讲了什么、重点是哪些」，再按知识点出题，质量高一个量级。

## 项目亮点

- **闭环思维**：不只是「生成试卷」，而是打通「学 → 测 → 反馈 → 补练」完整闭环
- **题型与能力匹配**：记概念用选择题、验应用用实操题，不搞一刀切
- **错题反馈机制**：学生错题 → AI 生成同知识点补练，形成自适应学习雏形
- **可落地的 Prompt 模板**：解析知识点、生成试卷、生成补练，3 套可直接复用
