# 学习评估 Skill

> 设计能真正检验学习效果的作业、测验和练习——让「学没学会」可以被看见、被检验。

## 这是什么

一个可落地的 Skill。课程讲完了，怎么知道学员「真学会了」还是「以为自己会了」？用它设计一套能检验学习效果的评估。

**核心认知**：评估不是为了「考倒学员」，而是为了「检验学习目标有没有达成」。

## 四步设计法

1. **定评估目标**：回到课程学习目标，「要检验什么能力」
2. **选题型**：根据要检验的能力，选对题型（实操题 > 选择题）
3. **分难度**：基础题 60% / 进阶题 30% / 挑战题 10%
4. **配反馈**：每题的答案解析 + 错题后的补救路径

## 怎么用

1. 打开 `SKILL.md`，里面有完整的操作框架、步骤、模板和检查清单
2. 把它当「操作手册」：接到对应工作时，照着步骤一步步走
3. 可以直接复制里面的「输出模板」，填入你的实际内容
