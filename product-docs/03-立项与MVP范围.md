# 立项报告与 MVP 范围

## 产品名称

**知测云（Zhi Ce Lab）**——AI 知识效果检测与学习诊断。

## 一句话定位

把课程材料转成可追溯、可审核、可诊断的 Assessment Package，而不只是生成几道题。

## 目标用户

教师、教研员、题库运营、企业培训负责人；学员是试答与反馈端用户。

## 核心问题

AI 可以快速生成题目，但答案可靠性、来源、蓝图覆盖、审核责任和诊断边界没有被产品化，导致“能生成”与“敢上线”之间存在断层。

## MVP 主链路

`材料 → Brief → 素材充分性 → 知识模型 → 蓝图 → 候选题 → 规则门禁 → 人工审核 → 学员试答 → 证据诊断 → JSON 导出`

## 范围

### Must
- 文本材料输入与充分性检查；
- 知识点与考试蓝图；
- 每知识点 2 道可追溯单选题；
- 质量摘要和人工审核门；
- 在线试答与三档诊断；
- localStorage 保存和 JSON 导出；
- 响应式与静态上线。

### Should
- 文件上传、题目逐条编辑、错题补练、灰度反馈入口。

### Later
- 服务端 LLM、组织/角色、题库版本、LMS 适配、真实作答统计与难度校准。

## 成功指标

MVP 技术指标：主流程可完成、结构验证通过、页面无阻塞错误、移动端可用。业务指标必须在灰度后以真实数据填写：生成耗时、审核通过率、人工修改率、完成率、再测变化。

## 风险

- 规则生成题仅用于验证交互链路，不等同于模型生成质量；
- 浏览器本地数据不支持多端协作；
- 静态站点没有组织权限和服务端审计；
- high 风险场景不允许自动发布或自动决策。
