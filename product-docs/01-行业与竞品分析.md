# 行业与竞品分析

## 1. 观察范围

公开案例重点参考 AI quiz generator 赛道常见产品：Quizizz、Kahoot、Quizgecko、QuestionWell、Conker、Questgen 等。公开搜索结果显示，多数产品共同强调 PDF/网页导入、多题型生成、快速发布、游戏化与 LMS 导出。

## 2. 市场共性

| 能力 | 常见成熟度 | 问题 |
|---|---:|---|
| 文档/PDF 转题 | 高 | 容易把“生成速度”当“测评质量” |
| 多题型与模板 | 高 | 题型多不等于能观察学习目标 |
| 在线答题/分享 | 高 | 分享链路成熟，但来源证据常被弱化 |
| 游戏化 | 高 | 提高参与度，不直接证明诊断有效 |
| LMS/表单导出 | 中高 | 依赖适配器，不能在未接入时虚构链接 |
| 蓝图与来源链 | 中低 | 教师难判断“为什么出这题” |
| 人工审核治理 | 中低 | AI 题目容易直接流入正式考试 |
| 证据式诊断 | 低 | 常以一次得分生成过强的能力标签 |

## 3. 差异化定位

**知测云不竞争“最快生成 30 道题”，竞争“让 AI 题目真正可审核、可上线、可诊断”。**

核心差异：

1. 先建立 Assessment Brief、知识模型和考试蓝图；
2. 每道题绑定知识点、目标、来源与解析；
3. medium/high 风险强制 Human-in-the-loop；
4. 生成难度明确标记 estimated，禁止冒充 calibrated；
5. 同一核心知识点至少 2 条独立证据；
6. 诊断使用 demonstrated / developing / insufficient evidence；
7. 支持结构化 Assessment Package 导出和机器验证。

## 4. MVP 不做

- 不在浏览器公开环境中内置模型密钥；
- 不承诺 PDF/OCR 全格式解析；
- 不接入真实 LMS 前不声称“已经发布到平台”；
- 不提供高风险考试自动决策；
- 不展示无真实样本支撑的区分度、可靠性和校准难度；
- 不收集学生姓名等不必要个人信息。

## 5. 机会判断

第一目标用户不是普通学生，而是需要对题目质量负责的教师、教研员、课程运营和企业培训负责人。进入点是“现有材料快速形成可审核检测包”，扩展点是题库治理、真实作答分析、补练与迁移再测。
