# 知测云｜AI 知识效果检测项目归档

## 一、项目结果

已将 GitHub 仓库 `learning-assessment-skill` 从方法论 Skill 落地为可上线的响应式 Web 产品“知测云（Zhi Ce Lab）”。

在线地址：https://macistone71-jpg.github.io/learning-assessment-skill/

GitHub：https://github.com/macistone71-jpg/learning-assessment-skill

产品定位：把课程材料转化为可追溯、可审核、可诊断的 Assessment Package，不只是快速生成几道题。

## 二、已上线功能

1. Assessment Brief：设置测评名称、目的、风险、学员、时长和来源；
2. 素材充分性检查：识别字符数、主题数和可考查陈述，不足时显示 SOURCE_GAP；
3. 知识模型：从章节形成知识点、学习目标与可观察证据；
4. 考试蓝图：每个知识点安排认知层级、难度、题型、题量和分值；
5. 候选题池：每个知识点生成 2 条独立证据题，每题绑定答案、解析与原文；
6. 质量门禁：检查唯一答案、来源、蓝图覆盖、重复、隐私和难度标记；
7. 人工审核：medium/high 风险未经审核不能进入学员端；
8. 学员试答：一次一题、四选一、本地记录，不采集姓名；
9. 证据诊断：输出 demonstrated、developing、insufficient evidence；
10. JSON 导出：导出完整 Assessment Package，供题库或平台适配。

## 四、测试结果

- Node 核心逻辑：25+ 断言通过；
- 原仓库 Python 验证器：Assessment Package structure is valid；
- 本地浏览器端到端：生成→审核门禁→人工审核→6 题试答→诊断报告通过；
- 风险门禁：medium 未审核时学员端被正确拦截；
- 诊断边界：只完成 1 条证据时不会输出 demonstrated；
- 移动端：390px 视口无横向溢出；
- GitHub Pages：构建状态 built，发布 commit 为 dd1900d。

## 五、产品差异化

主流 AI Quiz 产品普遍强调 PDF/网页导入、生成速度、多题型、游戏化和分享。知测云的差异化是：

- 先蓝图后出题；
- 每题有来源证据链；
- 中高风险强制人工审核；
- 预估难度不冒充真实校准难度；
- 每个核心知识点至少 2 条独立证据；
- 不把一次答错解释为“不会”；
- 结构化包可验证、可治理、可进入后续平台适配。

## 六、真实数据边界

当前没有虚构问卷、访谈、审核通过率、人工修改率、区分度、可靠性或学习提升。真实用户调研、题目效度、校准难度和再测变化必须来自真实样本；样本不足时统一标记“待校准”。
