# 知测云｜从 Skill 到上线产品执行总览

> 产品：AI 知识效果检测与学习诊断 Web MVP  
> 方法来源：`learning-assessment-skill`  
> 原则：不虚构调研数据、不虚构难度、不跳过人工审核、不把一次答错等同于“不会”。

| 顺序 | 阶段 | 本次交付 | 状态 |
|---|---|---|---|
| 1 | 产品阅读与行业积累 | 阅读完整 Skill、Schema、蓝图、诊断与门禁；检索 Quizizz、Quizgecko、QuestionWell 等公开案例 | ✅ |
| 2 | 行业分析报告 | 明确“快速出题”红海与“证据链+质量治理”差异化 | ✅ |
| 3 | 用户调研 | 基于既有 PRD/简历场景形成假设；真实 5–8 人灰度访谈待上线邀请，未虚构结论 | 🟡 |
| 4 | 竞品分析 | 形成竞品能力矩阵、机会点与不做清单 | ✅ |

## 今日可见结果

- 可在线访问的响应式产品；
- 可粘贴材料并执行素材充分性检查；
- 自动建立知识点、蓝图和 2× 独立证据题；
- medium/high 风险必须人工审核；
- 学员可完成试答并获得克制的三档证据诊断；
- 可导出符合 Skill 结构的 Assessment Package JSON；
- 核心逻辑保留在原 GitHub 仓库，支持持续迭代。

## 不能伪造的部分

真实用户调研、题目效度、校准难度、区分度、可靠性和学习提升必须来自真实样本。本次只完成技术灰度，不把自测冒充 5–8 名真实用户结果。
