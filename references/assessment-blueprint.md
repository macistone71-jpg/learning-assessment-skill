# 考试蓝图设计

蓝图是“学习目标如何被题目取证”的合同，先于题目生成。

## 必填维度

| 字段 | 说明 |
|---|---|
| knowledge_id | 知识点 ID |
| objective_id | 学习目标 ID |
| bloom_level | 认知层级 |
| item_type | 题型 |
| difficulty | easy/medium/hard，生成时为预估 |
| count | 题目数 |
| points | 分值 |
| evidence_rule | 达成目标需要的证据 |

## 设计规则

1. 先按测评目的分配证据，再决定题型。
2. 核心目标至少需要两条独立证据，题量不足时输出“证据不足”。
3. 低风险随堂测可以少题；高风险测评需要专业测量人员设计。
4. 题型必须能观察目标：应用目标不能只用概念识记题。
5. 难度分布不是固定比例；必须结合学员、目的和时长。
6. 总分、预计作答时间和题量必须互相一致。
7. 自动评分题与人工 Rubric 题分别标记。
8. 为无障碍需求准备等价形式，不能改变被测构念。

## 蓝图审核问题

- 是否有目标完全未覆盖？
- 是否有题目不服务任何目标？
- 是否把语言能力误当成学科能力？
- 是否用一道题就做高置信度诊断？
- 是否存在内容超纲或来源缺口？
- 是否能在规定时间内完成？
